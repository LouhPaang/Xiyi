# 希夷语言标准库与编译器近期开发规划 v0.1.9.6_Theta

《道德经》有云：「视之不见名曰夷，听之不闻名曰希。」
希夷之名，取诸此句。

## 1. 规划依据

本规划依据以下规范文档修订而成：

- 《希夷语言标准库主体条款》v0.1.9.6_Epsilon
- 《希夷语言特别修正案》v0.1.9.6_Zeta
- 《希夷语言标准库全览》v0.1.9.6_Delta
- 《希夷语言最小子集概要》v0.1.9.6_Delta

这使开发者于最短时间内，建立对希夷语言的整体认知。

## 2. 版本体系声明

### 2.1 与语义化版本的关系
希夷语言版本号**不遵循**《语义化版本 2.0.0》（Semantic Versioning 2.0.0）。
版本号格式、进位规则与希腊字母后缀的使用，以《版本号规定》为唯一准据。

### 2.2 版本号格式
版本号由前缀、四段数字与希腊字母后缀组成，格式如下：
vX.Y.Z.W_GreekLetter

其中：
* X — 主版本号，非负整数，不受单一位数限制。
* Y — 次版本号，取值范围 0–9。
* Z — 修改次数，取值范围 0–9。
* W — 补丁次数，取值范围 0–9。
* GreekLetter — 希腊字母后缀，标识同一补丁下的逐次修订，按《版本号规定》§5 所列 15 个可用字母顺序取用。

**约束：**
* 次版本号、修改次数、补丁次数**禁止**出现两位数。例：v0.1.10.6_Alpha 非法。
* 数字段与希腊字母之间**必须以**下划线 `_` 连接。使用连字符 `-` 或句点 `.` 均非法。
* 希腊字母用尽后**必须**执行进位规则，禁止自创后缀（如 Alpha2、-rc1 等）。

### 2.3 本规划所涉文档版本
本规划依据的规范文档**必须共享同一数字段** v0.1.9.6，方可视为一次有效迭代。
任何单份文件的独立版本号变更均不构成正式发布，仅视为草案预览。
